# Prompt di installazione — da mandare ai collaboratori

Messaggio da inviare:

> Ciao! Per installare lo strumento delle coperture Chapeau copia tutto il testo qui sotto e
> incollalo in **Claude Code** (oppure, se non l'hai ancora, nella chat di **Claude**): fa tutto
> lui e ti chiede solo quello che serve.

---

```text
Installa sul mio computer lo strumento "Coperture Chapeau" di Chapeau Media.
Repository: https://github.com/filippo-carabelli/chapeau-coperture

Io non sono un tecnico: parlami in italiano semplice, un passaggio alla volta, e chiedimi solo
quello che serve davvero.

SE SEI CLAUDE CODE (puoi eseguire comandi su questo computer):
1. Scarica il file delle istruzioni senza installare niente:
   - Mac: curl -fsSL https://raw.githubusercontent.com/filippo-carabelli/chapeau-coperture/main/INSTALLA.md
   - Windows (PowerShell): (Invoke-WebRequest -UseBasicParsing https://raw.githubusercontent.com/filippo-carabelli/chapeau-coperture/main/INSTALLA.md).Content
2. Leggilo tutto e seguilo dall'inizio alla fine: installa quello che manca partendo dal
   presupposto che su questo computer ci sia solo DaVinci Resolve, configura tutto, fai il test
   finale e dimmi in tre righe com'è andata e come si usa.

SE SEI CLAUDE NELLA CHAT (non puoi eseguire comandi sul mio computer):
non provare a installare tu. Aiutami a installare Claude Code con il minimo di passaggi:
- Dammi UN passaggio alla volta, spiegato in modo semplicissimo (dove cliccare, cosa copiare),
  e aspetta che ti scriva "fatto" prima del successivo. Se qualcosa va storto, aiutami.
- Strada consigliata: l'app desktop di Claude. 1) Vai su https://claude.ai/download e scarica
  la versione per il mio computer (chiedimi tu se ho un Mac o Windows). 2) Installala (Mac:
  apri il file scaricato e trascina Claude nella cartella Applicazioni; Windows: apri il file
  scaricato). 3) Apri Claude ed entra con il mio account. 4) Clicca la scheda "Code" in alto.
  5) Quando chiede una cartella, scegli "Documenti". Serve un piano Claude a pagamento (Pro o
  superiore): se non ce l'ho, dimmi di chiedere a Fil.
- Alla fine dimmi di incollare di nuovo QUESTO STESSO MESSAGGIO nella scheda Code: da lì
  Claude Code farà tutto da solo.
```
